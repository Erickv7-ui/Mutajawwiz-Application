Cara Pakai

  1. Pastikan status di panel atas berwarna hijau (Terhubung) sebelum menginput data.
  2. Ketik nama anggota → kelas & kamar terisi otomatis.
  3. Pilih bahasa → tulis ucapan → klik KIRIM ABSENSI.
  4. Data langsung masuk cloud — bisa dibuka dari HP/laptop lain, tidak hilang walau browser ditutup.
  5. Rekap bisa difilter per tanggal, kelas (tingkat 1/2/3/4), bahasa, cari nama, atau centang kelipatan.
  6. Klik EXPORT CSV buat download rekap yang sedang tampil, atau pakai panel Export Excel (XLSX) di bawah untuk file Excel rapi.

Export Excel (XLSX)

Format rapi · 1 sheet per tanggal

Unduh rekap absensi dalam file Excel yang sudah diformat sesuai template resmi (header berwarna, garis tabel, satu sheet untuk tiap tanggal). Semua filter bisa dipakai: rentang tanggal, kelas, bahasa, dan kelipatan.

Kolom Group terisi otomatis sesuai template resmi: Extreme untuk ucapan Javanese Language, Medium untuk Indonesian Language. Kolom Speaking ditulis penuh (Indonesian Language / Javanese Language), kolom Room memakai nomor kamar, dan kolom Class memakai tingkat kelas (1/2/3/4) sesuai template resmi.
